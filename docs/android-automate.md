# Android Automate 截图记账

**使用前请先了解：**Android 没有与 iPhone「快捷指令」完全相同的统一官方应用。本项目的安卓截图记账需要第三方应用 [Automate（LlamaLab）](https://www.llamalab.com/automate/)；是否安装以及是否授予截图、辅助功能等权限，由你自行决定。Automate 并非本项目或 Android 官方提供。不使用它也可以在网页手动记账。

项目附带可导入的 [「记一笔」Automate flow](../android/记一笔-Android-Automate.flo)。这个文件保留了截图、确认、修改和保存的原流程，使用部署者自己的 Cloudflare Pages `/api/recognize` 与 `/api/transactions`。它包含 30 个模块，符合 Automate 免费版的模块数量上限。

## 安装

1. 先在网页按自己的需要创建个人或家庭账本，在「我的 → 账本管理」确认默认账本，再复制「我的 → 固定用户名」。
2. 在 Android 手机上安装 Automate，将 `.flo` 文件下载到手机，在 Automate 的流程列表中导入它。
3. 第一次启动 flow 时，按提示分别填写部署后的网页首页地址和固定用户名。例如网页地址填 `https://你的项目.pages.dev/`。末尾有无 `/` 都可以。以后启动会沿用这两个值，不会每次都询问。
4. 按 Automate 和 Android 的提示授权截图、辅助功能及显示窗口权限，将「记账」加入快捷设置。打开支付页面，点快捷设置里的「记账」，核对识别信息和账本后再保存。

若填错网页地址或用户名，停止旧 flow，重新导入 `.flo` 文件并启动，重新回答两个问题；避免同时运行两个「记账」flow。Automate 的配置保存在本机的 atomic 变量中；修改或重新导入 flow 后会重新要求填写。

## 账本与接口

识别请求向 `<网页地址>/api/recognize` 发送截图 Base64 和 `user_key`。响应中的 `books` 只包含该用户名下的账本，网页设置的默认账本排在第一位。没有账本时，商户、金额等识别草稿仍可显示，账本留空；需要先在网页建账本才能保存。

确认或修改信息后，flow 向 `<网页地址>/api/transactions` 发送同一个 `user_key`、选中的账本名和账单字段。修改页面可以临时选择本人名下的其他账本，不会更改网页默认账本。每位共用同一 Pages 项目的成员在自己的手机上填写各自的固定用户名。

Automate 可把 flow 导出成 `.flo` 文件分享，适合直接放入 GitHub 仓库；也有社区分享功能。分享前请确认 flow 中没有自己真实的网页地址、用户名、账单或截图。本仓库的 `.flo` 不包含这些个人值。修改 flow 后请在 Android 设备上重新完成一次截图、确认、保存和网页核对。

目前的保存请求在用户确认时生成交易编号。若网络超时、无法确定是否保存成功，先在网页检查这笔记录，再决定是否重试，以免重复记账。

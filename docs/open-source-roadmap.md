# 开源版路线图

正式部署使用 Cloudflare Pages、Pages Functions、D1 与 Workers AI。网页和快捷指令共用 `https://项目名.pages.dev/api`，一个家庭使用自己独立的项目和数据库。

## 已实现

- 个人与家庭账本、默认目标、账单同步、分页、删除墓碑和重试幂等协议。
- Pages Functions 中的同域 `/api/*`，D1 表结构与 Workers AI 识别、语音草稿接口。
- 创建或复用 Cloudflare 资源的安装脚本，以及模拟 D1 和部署脚本测试。

## 发布前验收

1. 在全新 Cloudflare 账号运行安装流程，检查 D1、Pages 和 AI 绑定。
2. 从不使用 VPN 的目标手机网络上传真实中文支付截图，核对模型字段与响应时间。
3. 检查 iPhone 快捷指令的安装问题、识别与保存请求、错误提示和确认后写入。现有指令未发送稳定的 `client_id`；网络超时后先到网页核对，再决定是否重试。
4. 检查两个成员的默认账本、家庭汇总、网页同步与跨设备恢复。
5. 确定 D1 备份、恢复、费用告警和公开 API 限流方案。

当前 `user_key` 只负责家庭内部区分，不提供安全认证。如果要提供公共多租户服务，需要先设计身份验证、访问控制与隔离。

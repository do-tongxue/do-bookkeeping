# iPhone 截图快捷记账

下方共享快捷指令已核对安装问题和请求字段。它使用部署者自己的 Pages 网址，安装时填写固定用户名，完成截图识别、选择本人账本和保存流水。

把下面的完整网址复制到 iPhone Safari 安装：

```text
https://www.icloud.com/shortcuts/1440b2e43baf42d5a245d21b4c4ba445
```

安装时填写两个问题：网页首页地址，末尾保留 `/`，例如 `https://你的项目.pages.dev/`；以及网页「我的 → 固定用户名」显示的内容。快捷指令会自动拼出 `/api/recognize` 和 `/api/transactions`，不需要分别填写接口网址。

## 使用顺序

1. 在网页创建个人或家庭账本，确认默认账本，并复制自己的固定用户名。
2. 安装快捷指令，填写自己的网页地址和固定用户名；每位家庭成员在自己的手机上填写自己的用户名。
3. 在 iPhone 运行快捷指令并截取支付页面。识别完成后检查商户、金额、时间、分类、备注和账本。
4. 选择“直接记账”，或先用“修改信息”调整字段，再确认。返回网页检查流水是否出现。

## 现有快捷指令使用的接口字段

识别请求发送 `image` Base64 和 `user_key`。Cloudflare `/api/recognize` 先返回商户等草稿字段，再附上该用户名下的 `books` 字符串列表，并把网页设置的默认账本排在第一项。没有账本时返回空列表，不会自动创建账本。快捷指令读取 `books` 的第一项，也能在“修改账本”中从本人列表选择其他账本；本次改选不会改变网页默认设置。

保存请求发送同一个 `user_key`，以及 `merchant`、`amount`、`datetime`、`category`、`note`、`book` 和 `source`。Cloudflare `/api/transactions` 根据用户名和账本名找到实际账本，写入 D1；本指令无需发送 `target_id` 或 `client_id`。新的客户端仍可使用 `target_id` 和稳定的 `client_id` 进行幂等写入。

由于现有指令没有交易唯一编号，同一笔请求在网络不确定时重复提交，可能产生两笔相同流水。遇到超时先到网页核对，避免盲目重试。

## 适用范围与排查

多人共用同一部署时，每位成员在快捷指令中填写各自的固定用户名，即可自动读取自己的默认账本。当前“修改账本”只显示本人名下的账本；即使同在一本家庭大账本里，也不能用这份快捷指令替其他成员记账。未传 `user_key` 的旧指令在多人部署下会看到“请选择账本”，以避免猜测归属；这份新指令正常配置后不会显示该占位项。

- `/api/health` 返回 `ok: true` 只说明数据库和 AI 绑定可用，不代表截图识别、账本读取和保存流程已经完成。
- 识别成功但账本为空：先检查网页是否已创建账本、安装时填写的固定用户名是否与网页完全相同，以及快捷指令是否请求了自己的 Pages `/api/recognize`。即使账本为空，商户和金额等草稿信息仍可返回，但不能直接保存。
- 保存后网页没有流水：先核对保存请求是否指向同一 Pages 项目的 `/api/transactions`，再看返回的 `ok` 和 `error`。

# 开源版安装提示词

用户按下面五步操作。部署使用项目脚本；电脑需安装 Node.js 22.13+。`{网页地址}` 由脚本自动给出。

1. **授权 Cloudflare**：下载项目，在项目文件夹运行 `npm run install:all`，按浏览器提示登录并授权 Cloudflare。
2. **等待自动部署**：授权后，程序会自动创建数据库、部署网页和接口。完成时保存显示的 `{网页地址}`。
3. **在网页建账**：打开 `{网页地址}`，按自己的需要创建个人或家庭账本，在「我的 → 账本管理」确认默认账本，再到「我的 → 固定用户名」复制用户名。
4. **按手机系统安装记账工具，只选一种**：

   - **iPhone（iOS）**：把下面的链接复制到 iPhone Safari 打开，安装「快捷指令」。安装时填写 `{网页地址}`（末尾保留 `/`）和刚复制的固定用户名。

     ```text
     https://www.icloud.com/shortcuts/1440b2e43baf42d5a245d21b4c4ba445
     ```

   - **Android**：Android 没有与 iPhone「快捷指令」完全相同的统一官方应用。本项目的安卓截图记账需要第三方 [Automate](https://www.llamalab.com/automate/)；是否安装及授予截图等权限由用户自行决定，不使用也可以在网页手动记账。如选择使用，先安装 Automate，再下载源码包中的 [`android/记一笔-Android-Automate.flo`](../android/记一笔-Android-Automate.flo) 并导入。第一次启动 flow 时填写 `{网页地址}` 和刚复制的固定用户名。**Android 用 `.flo` 文件，不用上面的 iCloud 链接。**

5. **截图测试**：iPhone 用快捷指令、Android 用 Automate 的「记账」快捷设置按钮截取支付页面；核对识别信息和账本后确认保存，再到网页核对流水。

两种手机端工具都会使用用户填写的网页地址与固定用户名，自动请求对应的识别和保存接口。多人共用同一个 Pages 项目时，每人填写自己的固定用户名，就会优先显示这个人在网页设置的默认账本；临时修改账本不会改变网页默认设置。

这份提示词保持中性：不预设用户的家庭关系，也不要求所有人创建家庭账本。手机端详细说明分别见 [iPhone 快捷指令](iphone-shortcut.md)和 [Android Automate](android-automate.md)。安装命令启动后才会请求 Cloudflare 授权；授权完成后的数据库、网页和接口部署由脚本自动执行。
